# QueryBridge SCM / TAIJU Knowledge Pack

This folder consolidates prior working knowledge from discussions about TAIJU / SCM Cockpit, SAP, Project Procure, VIM, P6, DPPP, TSP, Power BI and SCM digitalisation.

## Status labels

- **Established context** — repeatedly used or explicitly stated in prior discussions.
- **Working design / validate** — a proposed architecture, mapping or modelling pattern that should be checked against the live implementation before treating it as authoritative.
- **Evidence sample** — observations from specific QAS/sample data. These are useful for rule design, but must not be treated as production-wide facts.
